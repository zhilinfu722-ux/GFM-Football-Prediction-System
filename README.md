# GFM 足球预测系统（本地版 V1.2）

本项目为 Windows 优先的本地网页应用，使用 Streamlit + Python + SQLite。默认不需要云服务器或付费 API；可先用 CSV 历史赛果运行。联网数据源需用户自行注册并配置 API Token。

## 一、快速启动（Windows）

1. 安装 Python 3.10 或更高版本：https://www.python.org/downloads/ 。安装时勾选 **Add Python to PATH**。
2. 解压整个项目文件夹，不要只运行压缩包里的单个文件。
3. 双击 `START_GFM.bat`。
4. 首次启动会创建 `.venv` 并安装依赖，随后启动网页。
5. 浏览器打开 `http://localhost:8501`（通常会自动打开）。

首次安装需要联网下载 Python 依赖。后续启动会复用本地虚拟环境。

## 二、首次使用

1. 打开「历史数据导入」，导入 CSV。
2. CSV 至少包含 `Date,HomeTeam,AwayTeam,FTHG,FTAG` 五列。
3. 打开「赛事管理」手动创建即将进行的比赛，或配置 API 后同步赛程。
4. 打开「比赛预测」，选择比赛并运行预测。
5. 保存预测后，赛后在「赛果录入」填写实际比分。
6. 在「历史回测」执行按时间顺序的 walk-forward 回测。

## 三、数据源配置（可选）

复制 `.env.example` 为 `.env`，填入自己的密钥：

```dotenv
FOOTBALL_DATA_TOKEN=your_token
API_FOOTBALL_KEY=your_key
```

密钥不会写入数据库。不要把 `.env` 上传到 GitHub 或发送给他人。免费套餐覆盖和限额由供应商决定，使用前核对赛事、赛季、接口权限及授权条款。

## 四、模型说明

当前模型版本：`GFM-1.2.0-elo-poisson-dc`

- 时间衰减的主场进攻/防守、客场进攻/防守估计。
- 小样本向联赛平均值收缩。
- 基于历史赛果逐场更新的 Elo 实力评分。
- Poisson 比分矩阵。
- 对 0-0、0-1、1-0、1-1 做固定 rho 的 Dixon-Coles 低比分修正。
- 输出主胜/平局/客胜概率、预期进球、双方进球概率、最可能比分和热门方不胜风险。

重要：这是可运行的研究基线，不代表已验证的盈利或高准确率模型。固定 Dixon-Coles 参数尚未按联赛训练；Elo 和进球模型也尚未完成联赛级校准。回测结果必须与简单基准比较，并避免数据源覆盖不一致导致偏差。

## 五、数据库与备份

数据库位于 `data/gfm.db`。预测记录保留模型版本、创建时间和输入摘要。建议每天结束后双击 `BACKUP_GFM.bat`，或在网页「预测记录与备份」下载数据库副本。

## 六、测试

```bash
.venv\Scripts\python.exe -m pytest -q
```

## 七、常见问题

- **启动提示找不到 Python**：安装 Python 3.10+，勾选 Add Python to PATH。
- **依赖安装失败**：检查网络后重新运行 `START_GFM.bat`。
- **没有可预测比赛**：先导入历史 CSV，再手动创建未来比赛或同步 API 赛程。
- **预测提示没有历史赛果**：当前预测需要至少一些已完赛的历史数据；样本越少，结果越不稳定。
- **API 401/403**：密钥无效或套餐不覆盖所选赛事/接口。
- **API 429**：达到请求限额，请等待额度恢复。
